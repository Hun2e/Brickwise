- 상태: 완료 (2026-10-23, 사용자 요청 — 요구 항목이 구체적이라 결정 지점 없이 PM 기본안으로 진행)
- 관련 요구사항: F2013(HTML/CSS/JS 화면), F2008(근거 표시), F2009(항목별 기록), F2011(카드 선택 후 질문), F2012(진행 상태·안내)
- 선행 작업: T-025·T-026 (커밋 341213b)

## 배경
지금 웹은 왼쪽 보조 패널·가운데 대화·오른쪽 근거 패널의 3단 구조에 "현재 대상" 카드, 변경·해제 버튼, 컬렉션 표 편집기가 한 화면에 모두 보인다. 처음 쓰는 사람은 어디서부터 해야 할지 알기 어렵다. Streamlit처럼 **대화창 하나**가 중심이 되게 바꾼다.

## 범위
- 포함 (웹 `web/`만)
  1. **첫 화면**: 대화가 없으면 "어떤 레고를 찾고 있나요?" 제목, 한 줄 설명("세트를 찾고, 궁금한 걸 묻고, 가진 레고로 만들 수 있는 걸 추천받아요"), 질문 예시 버튼 4개. 누르면 그 질문을 바로 보낸다. 예시 문구는 `web/js/` 상수로 둔다.
  2. **대화 영역**: 가운데 넓은 단일 열(데스크톱 최대 폭 약 820px, 모바일 전체 폭). 입력창은 **화면 아래에 고정**하고, 새 답변이 오면 아래로 스크롤한다. Enter로 보내기, Shift+Enter로 줄바꿈.
  3. **현재 대상**: 입력창 바로 위에 "지금 이야기 중: {짧은 이름} {번호}"(예: "지금 이야기 중: X-wing 75301") 한 줄 칩과 [✕](대상 끝내기). 대상이 없으면 숨긴다. 대상 바꾸기는 별도 패널 대신 카드의 [자세히 물어보기]나 질문("75192 알려줘")으로 한다. 짧은 이름은 세트 이름을 그대로 쓰되 30자에서 자른다(번호 접미 `-1`은 표시에서 뺀다).
  4. **오른쪽 근거 패널 제거** → 답변마다 아래에 접힌 **"출처 보기 (N)"**. 펼치면 인용 근거 카드(번호·출처 종류를 쉬운 말로 "레고 데이터"/"위키백과"·제목·원문 링크·라이선스·발췌). 답변 속 `[근거 N]`을 누르면 그 답변의 "출처 보기"가 펼쳐지고 해당 카드로 스크롤·강조. 인용이 없으면 접힌 영역 안에 "답변에 인용된 근거가 없습니다"(F2008).
  5. **진행 상태**: 처리 중에는 답변 자리에 "찾는 중… (문서 수집: Return of the Jedi)"처럼 현재 단계 한 줄을 보이고, 끝나면 **"처리 과정"** 접기 안에 단계 목록을 남긴다(F2012). 경로·소요 시간 같은 내부 정보도 이 접기 안으로.
  6. **왼쪽 접이식 메뉴(☰)**: 데스크톱·모바일 모두 기본 닫힘, 열면 왼쪽 서랍(모바일은 화면 위에 덮고 바깥 누르면 닫힘). 섹션:
     - **대화 기록**: 대화 목록(제목·시각), 선택하면 열기, 이 대화 지우기
     - **내가 가진 레고**: 보유 세트 목록(이름·번호·수량)과 수량 고치기·빼기, "세트 추가"(세트 검색 상자). 기존 컬렉션 편집 기능·version 충돌 안내 유지. 용어 "컬렉션" → "내가 가진 레고".
     - **이 세트 이야기 기록**: 현재 대상의 세트별 기록(F2009). 대상이 없으면 "세트를 정하면 그 세트와 나눈 이야기만 모아 보여 줘요".
  7. **검색·추천 카드**: 핵심 정보만 — 번호 배지, 세트 이름, "2021년 · 474개 부품", 추천이면 "부품 86개 더 필요". 버튼 두 개:
     - **[자세히 물어보기]**: 그 세트를 현재 대상으로 정하고(기존 subject 변경 API) 입력창에 포커스·안내 문구("{이름}에 대해 물어보세요"). 화면 이동 없음(F2011).
     - **[갖고 있어요]**: 기존 [보유 등록]과 같은 동작(같은 대화에 등록 요청, 멱등). 성공하면 버튼이 "✓ 가지고 있어요"로 바뀐다.
  8. **쉬운 말 정리**: 화면 문구에서 내부 용어를 줄인다 — "근거 패널"→"출처", "보유 등록"→"갖고 있어요", "현재 대상"→"지금 이야기 중", "컬렉션"→"내가 가진 레고", "세트별 기록"→"이 세트 이야기 기록". 출처 종류 배지: set_meta·db → "레고 데이터", wikipedia → "위키백과"(원래 값은 `title` 속성으로 유지, F2016).
  9. **상태 안내**: 정상일 때 상태 배지를 숨기고, 키 없음·색인 없음 등일 때만 상단 안내 띠와 입력 비활성(F2012).
  10. 테스트: `web/tests/*.test.mjs`, `tests/test_web_static.py`를 새 화면 계약으로 갱신한다. 기존 의미(F2008 인용 일치·인용 0건 안내, F2009 기록 분리, F2011 카드 선택 후 같은 대화, 멱등 등록, 새로고침 복원, innerHTML 금지, 외부 CDN 금지)는 **삭제하지 말고 새 구조로 검증**한다.
- 제외
  - 백엔드(`server/`, `src/`) 변경 — 필요한 경우 남은 이슈로 보고만 한다. API·응답 형식 그대로 사용.
  - Streamlit 화면(이번엔 웹만). 단, "내 컬렉션" 문구만 "내가 가진 레고"로 맞추는 것은 허용(`app_streamlit.py` 문자열만).
