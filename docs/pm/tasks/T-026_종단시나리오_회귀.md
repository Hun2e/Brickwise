## 시나리오 파일 형식 (판정기 계약 — 파일 내용은 Codex 비공개)
```jsonc
{"id": "DS-01", "title": "...", "setup": {"collection": [["75257-1", 1]]},   // 시작 컬렉션(임시 user DB)
 "turns": [{"q": "질문", "expect": {
    "route": "filter|fact|narrative|compare|build|build_archive|set_ops|collection",  // 응답 route
    "subject": "75301-1",                 // 턴 뒤 현재 대상
    "subject_is_list_rank": 1,            // 턴 뒤 대상 = 직전 턴까지의 last_list.items[rank-1]
    "list_kind": "search|recommend|candidates",
    "list_contains": ["..."], "list_excludes": ["..."],   // 턴 뒤 last_list.items
    "collection": {"75301-1": 1},         // 턴 뒤 보유 목록 전체(빈 객체 = 비어 있음)
    "mode": "exact|ignore_color",
    "compare_includes": ["..."],
    "must_include": ["..."], "must_not_include": ["..."],  // 답변 본문 부분 문자열(숫자 콤마 정규화)
    "clarify": true}}]}                   // 되묻기(pending) 발생 여부
```
- 지정한 키만 판정한다. 시나리오별·턴별 통과/실패와 실패 이유(기대·실제)를 기록한다.
- 반복(`--reps`)마다 새 사용자·새 대화·새 임시 user DB를 쓴다. 운영 `data/user.sqlite`는 열지 않는다(설정 경로 자체를 임시 경로로 덮어쓴다 — T-024 리뷰 교훈).
