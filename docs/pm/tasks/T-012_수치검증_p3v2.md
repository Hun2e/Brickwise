## 설계 (검토 포인트 ①~⑥)

### ① 허용 집합의 범위
- (a) **답변이 인용한 카드 전체의 숫자** [초안 권장 — 실측 오탐 3/166, 정규화 후 0 예상]
- (b) LLM에 넘긴 모든 카드 — 느슨하다. 인용하지 않은 카드의 숫자를 써도 통과한다.
- (c) **같은 문장이 인용한 카드**만 — 가장 엄격하다. 한 문장에 숫자와 인용 위치가 어긋나면 정상 문장도 지운다.
- 공통으로 포함: 질문 원문의 숫자(사용자가 말한 "부족 60개 이하" 등), 인용 번호 자체(`[근거 N]`), 서수·단위 없는 소수(1·2 단계 목록 번호 등 — ③ 참조)

### ② 정규화 규칙
- 숫자: 콤마 제거(`7,541` = `7541`), 소수(`52.0%`의 `52.0` = `52`), 퍼센트 기호 제거
- 세트 번호: `75192` ≡ `75192-1`. 접미사가 다르면(`4504-2`) 정확히 비교한다.
- 카드 쪽 영어 숫자 단어 → 숫자 (zero~twenty, thirty~ninety, hundred, thousand. 복합 단어 `twenty-one`도 처리)
- 연도: 4자리 숫자는 일반 숫자와 같은 규칙이다 (카드에 있어야 함)

### ③ 검사 대상에서 제외할 숫자
- 마크다운 목록 번호(`1.` `2)`)와 제목 번호
- `[근거 N]` 표기 안의 N
- 한 자리 수 중 단위가 없는 것 — 오탐 방지
  - (a) 제외 [초안 권장]
  - (b) 검사

### ④ 위반 처리 (ADR-012 결정 3)
- 위반 문장을 지우고 `warnings`에 "검증되지 않은 수치를 포함한 문장 N개를 제외했습니다"를 남긴다.
- `verification` 필드에 `{checked, removed, items: [{value, sentence_index}]}`를 담는다. 화면 노출은 M5에서 정하고, 로그에는 전체를 남긴다.
- 제거 후 본문이 비거나 인용이 0이 되면 "제공된 자료에서 확인되지 않습니다"로 대체하고 `no_citation` 안내를 유지한다.
- DB에 없는 세트 번호(`SETNUM` 패턴인데 `sets`에 없음)는 근거 카드와 무관하게 위반으로 본다.

### ⑤ p3-v2 변경점
1. **지시어 해석**: 질문의 "이 기체/이 세트/이거"는 [선택 세트]가 묘사하는 대상(세트명·관련 엔티티)으로 해석한다. 레고 제품 자체 정보(설계자·출시 가격 등)는 근거에 있을 때만 답한다.
2. **길이·형식**
   - 핵심 답 1~2문장으로 시작한다.
   - 근거 기반 보충은 최대 `verify.p3_max_bullets`(기본 6)개 항목이다.
   - **표(`tables`)로 제공되는 행 데이터를 문장으로 반복하지 않는다.** 비교는 추세·차이 요약으로 쓴다.
   - 되묻는 제안 문장("원하시면 …")은 쓰지 않는다.
3. **숫자 표기**: 근거에 있는 숫자 표기를 그대로 쓴다 (세트 번호는 `NNNNN-N` 형식, 영어 수 단어는 원문 그대로 또는 근거에 있는 숫자로).
4. 기존 v1 규칙(근거만 사용, 확인되지 않음, 인용, 시리즈 목록 제한)은 유지한다.
- 오케스트레이터가 compare·build_archive에서 표가 있음을 P3 입력에 알린다 ("화면에 표로 제공됨: 판본 비교").

### ⑥ v1 vs v2 비교와 교체 기준
- `eval/p3_questions.jsonl`: T-008 대표 10문항 + T-011 S1·S2·S5 = 13문항
- `compare_p3.py`: 질문마다 **같은 근거 카드**로 v1·v2를 각각 생성한다. 기록 항목은 다음과 같다.
  - 답변
  - 문장 수
  - 인용 수
  - 검증 제거 수
  - 지연·토큰
- PM 판정 기준
  - 정확도·충실도가 v1 이상
  - Q1 지시어 해석이 해결됨
  - 평균 문장 수 감소
  - 검증 제거 0
  - → 모두 충족하면 기본값을 v2로 바꾼다
